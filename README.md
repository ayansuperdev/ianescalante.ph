## 🌐 Deploying Updates via GitHub & Vercel
1. Any changes pushed to `main` branch trigger automatic live builds.
2. To connect Vercel to your GitHub repo:
   - Log into [Vercel Dashboard](https://vercel.com/dashboard).
   - Add New Project -> Import `ayansuperdev/ianescalante.ph`.
   - Set Root Directory to `./` and Deploy.
